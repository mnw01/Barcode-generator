# 批量条码生成系统 (Barcode Generator System)

这是一个专为生产制造和仓储物流设计的批量条码打印工具。支持 Excel 导入、智能数据映射、历史记录云端同步以及精细化的打印控制。

## 核心功能

1.  **批量生成**：一键导入 Excel，批量生成 Code128 工业条码。
2.  **智能处理**：
    *   **自动周数**：P/I 号自动追加当前周数（例如 `DI-3075` -> `DI-3075 6`）。
    *   **倍数打印**：可设置打印数量倍数。
3.  **打印机控制**：
    *   **打印机锁定**：支持指定特定打印机。
    *   **边距微调**：支持 X/Y 轴毫米级偏移微调。
    *   **多模式**：支持热敏纸 (100x100, 70x40) 和 A4 PDF 导出。
4.  **云端协作**：
    *   **Supabase 集成**：支持多台电脑通过云端数据库同步历史记录。
    *   **双模式**：支持本地/云端无缝切换。

## 安装与运行

### 方式一：直接运行 (推荐开发者)
确保已安装 Python 3.10+。

1.  安装依赖：
    ```bash
    pip install -r requirements.txt
    ```
2.  运行程序：
    ```bash
    python main.py
    ```

### 方式二：打包为 EXE (推荐最终用户)
在 Windows 环境下，使用以下命令打包成无需 Python 环境的 `BarcodeGenerator.exe`：
```bash
pyinstaller --noconfirm --onedir --windowed --name "BarcodeGenerator" --add-data "C:/Windows/Fonts/msyh.ttc;." main.py
```
打包完成后，将 `dist/BarcodeGenerator` 文件夹发给用户即可。

## 使用说明

### 1. 基础设置 (Settings)
首次使用前，请进入 **“设置”** 页面进行配置：

*   **Excel 列映射**：设置 Excel 列名与系统字段的对应关系（如“产品编号”->“Barcode Source”）。
*   **条码来源**：选择哪一列的数据用于生成条码。
*   **打印倍数**：设置默认的打印数量倍数。

### 2. 云端同步配置
如果要启用多端历史记录共享：
1.  进入 **“设置” -> “云端同步”**。
2.  勾选 **“启用云端同步”**。
3.  填入 `Supabase URL` 和 `Anon Key`。
4.  保存并重启软件。

### 3. 日常使用流程
1.  **导入**：在首页点击“导入 Excel”或直接拖拽文件。
2.  **预览验证**：检查列表预览。
    *   *系统会自动在 P/I 号后追加当周周数。*
3.  **打印设置** (左侧栏)：
    *   选择 **纸张类型**。
    *   选择 **目标打印机**。
    *   **偏移调整**：输入毫米数修正 X/Y 偏移。
4.  **输出**：可直接点击“打印”或“生成 PDF”。

### 4. 历史记录查询
*   在“历史记录”页查看所有已导入的批次。
*   双击记录查看详情和补打标签。
